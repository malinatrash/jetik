# Changelog

## 0.1.0

First release.

- Git log tool window: branches tree, commit graph, commit details, filters by text, author and branch.
- Commit actions: cherry-pick, squash, edit message, fixup with local changes, drop, revert, reset, undo commit,
  checkout revision, compare with local, push up to here, new branch, new tag.
- Branch actions: checkout, rebase current onto, merge into current, checkout and rebase onto, compare,
  pull using rebase or merge, update, push, rename, delete.
- Commit tool window: per-file commit, amend, commit and push, rollback, issue key prefix, stash and unstash.
- Push dialog with outgoing commits preview, force with lease, rejected-push recovery, merge request link.
- Undo Last Git Operation, Smart Checkout, branch cleanup, background fetch.
- Conflict flow for stopped rebase, merge and cherry-pick.
- Multi-repository workspaces with a repository switcher.
- IntelliJ keymap.
